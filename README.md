# Quem Sou Eu?

App web no estilo do Impostor para jogar **Quem sou eu?** no celular.

## Como funciona

1. Adicione os jogadores (a ordem define a ordem da revelação).
2. Cada um escolhe um tema e escreve uma palavra em segredo.
3. As palavras são redistribuídas: **ninguém recebe a própria**.
4. Na mesma ordem, cada jogador arrasta o card para cima e descobre quem é.

## Desenvolvimento

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
